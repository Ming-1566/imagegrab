# 图提取 ImageGrab

Chrome Manifest V3 扩展。在淘宝、天猫、京东、拼多多商家版的商品详情页提取商品图片，于新标签页预览、勾选，并批量下载为真正的 PNG 文件。

## 安装

1. 使用 Chrome 或基于 Chromium 的浏览器（需支持 Manifest V3）。
2. 打开 `chrome://extensions/`。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本目录（包含 `manifest.json` 的 `ImageGrab` 文件夹）。
5. 安装后，前往目标电商的商品详情页即可使用。无需额外构建步骤。

## 使用

1. 打开淘宝、天猫、京东或拼多多商家版的**商品详情页**。非详情页不会显示按钮。
2. 建议先滚动页面，让主图、SKU 图和详情长图完成懒加载。
3. 点击右下角「获取图片」。
4. 扩展会新开 `gallery.html` 预览页，以网格显示图片、尺寸和复选框。
5. 使用「全选」「反选」，确认「已选」数量后点击「下载选中」。
6. 文件保存到浏览器默认下载目录，命名为 `商品图_001.png`、`商品图_002.png` 这类补零序号。
7. 预览页会显示下载进度、成功数量和失败原因。

JPG、WebP 等格式会在预览页用 canvas 解码后再导出 PNG，不是只改后缀。下载时先在预览页取图并转换，再用 `chrome.downloads.download` 保存。

## 测试方法

尚未在真实电商页面做完整浏览器验收，建议按以下清单自行验证：

1. **按钮显示**
   - 打开商品详情页（例如淘宝 `item.taobao.com/item.htm`、天猫 `detail.tmall.com/item.htm`、京东 `item.jd.com/*.html`、拼多多 `goods.html` 或商家后台商品详情）。
   - 右下角应出现「获取图片」。
   - 打开首页、搜索页、店铺页时，按钮应不出现。
2. **提取**
   - 先不滚动直接提取，再滚动加载详情图后再次提取，对比数量。
   - 预览页应去掉明显小于 100×100 的图标和占位图。
3. **下载**
   - 勾选少量图片下载，确认文件名为 `商品图_001.png` 起。
   - 用看图软件或文件属性确认 MIME/格式为 PNG，而不是把 `.jpg` 改名为 `.png`。
   - 故意勾选一张会失败的地址（或断网后下载），确认进度区出现失败原因。

## 已知限制

- 详情图多为懒加载。未滚动时可能只提取到主图或占位图；此时会提示先滚动页面。
- 默认丢弃小于 100×100 的图片。部分合法小图（如极小的色块 SKU）也可能被过滤。
- 跨域图片在预览页直接拉取并转 PNG；扩展消息通道只传 JSON/Base64，不传二进制。未列入权限的 CDN、防盗链过严或需要登录态的地址可能预览失败或下载失败。
- 部分平台会把缩略图后缀写成 `_400x400.jpg` 等，扩展会尽量还原大图，但不能保证每一张都有原图地址。
- 批量下载使用浏览器默认下载目录，不会弹出逐张「另存为」。若浏览器开启了“下载前询问”，仍可能多次确认。
- Service Worker 不进行 PNG 转换；转换只在 `gallery.html` 页面里用 canvas 完成。
- 当前仅覆盖淘宝、天猫、京东、拼多多相关域名及其常见图片 CDN。静态宣传官网已放在 `docs/`，未上架扩展商店，也未自动推送或发布。

## 权限说明

- `downloads`：调用 `chrome.downloads.download` 保存 PNG。
- `storage`：用 `chrome.storage.session` 在内容脚本和预览页之间传递提取结果。
- 站点与 CDN 的 `host_permissions`：注入商品页脚本，并从扩展上下文读取跨域商品图。内容脚本只负责提取 URL，不在页面里做跨域解码。

## 静态宣传官网

- 在资源管理器中双击 `docs/index.html` 即可本地预览，无需安装依赖。
- 页面包含可勾选的 SVG 画廊示意，已标明“界面示意”，不是实际插件测试截图。
- 安装包路径为 `docs/downloads/imagegrab.zip`，包含当前扩展运行文件和安装说明。修改扩展后应重新打包。
- 官网主要文件是 `docs/index.html`、`docs/css/style.css`、`docs/js/main.js`。
- 完整预览、GitHub Pages 发布与作业截图说明见 `docs/README.md`。
