03 / 四步开始使用

装进浏览器，
就能开始整理图片。

下载的是可本地加载的扩展源码包。
按以下步骤在 Chrome 中安装。

  1. 01

    下载并解压

    下载插件 ZIP，将全部文件解压到一个固定文件夹，保留其中的 manifest.json。

    下载压缩包
  2. 02

    打开扩展管理页

    打开 Chrome，将以下地址粘贴到顶部地址栏并回车。

    chrome://extensions
  3. 03

    开启开发者模式

    在扩展程序管理页右上角，打开「开发者模式」开关。

    开发者模式
  4. 04

    加载插件文件夹

    点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。

    然后刷新商品详情页
使用前的小提示

先向下滚动商品页，让懒加载图片出现。部分需要登录、未授权 CDN 或有防盗链限制的图片可能无法提取或下载，请以实际结果为准。

为什么页面没有「获取图片」按钮？＋

请确认扩展已启用，当前页面是支持平台的商品详情页。安装或重新加载扩展后，刷新商品页面；首页、搜索页和店铺页不一定会显示入口。

为什么下载成功的数量可能少于勾选数量？＋

图片可能受登录态、图片 CDN 权限、防盗链或解码格式限制。请查看画廊中的失败原因，先用少量图片测试。官网的画廊仅为界面示意，不代表实际平台的测试结果。

插件升级后，怎样使用新版本？＋

用新文件替换原扩展目录，在扩展管理页点击重新加载，再刷新已打开的商品详情页。
